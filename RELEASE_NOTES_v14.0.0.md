# AION EMS Zeus v14.0.0 — Stable Release

AION EMS Zeus 14.0.0 is the first stable release from the confirmed-working
`14.0.0-alpha.172` codebase.

## Stable status
- Same functional code and UI as `14.0.0-alpha.172`
- No new feature or behavior changes introduced during promotion
- GitHub/HACS release is no longer an alpha prerelease
- HACS users no longer need `Show beta versions` enabled to receive this release

- Simplified Finance
