# AION EMS Zeus v16.0.505 — A More Colorful Zeus

## Changes since v16.0.501

- **Overview & Briefing:** refined energy-category colors, subtle card accents and clearer visual hierarchy, preserving existing layouts and calculations.
- **Home Energy Timeline:** reduced repetitive grid import/export events with sustained thresholds, hysteresis and duration filtering; existing device events remain available.
- **Landing Page:** added a centered local date and live 24-hour clock above Overall Efficiency and Solar Self-Sufficiency.

## Compatibility

Forecast V2 remains the production engine. V2.1 and multi-array forecast evidence remain shadow-only. No forecast-control or energy-calculation changes are intended in this release.

Thanks to the Zeus community for the feedback and testing! ⚡
