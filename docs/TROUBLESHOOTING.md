# Troubleshooting — v11.7.4

1. Restart Home Assistant after replacing the integration folder.
2. Hard-refresh with Ctrl+F5 or fully close/reopen the mobile app.
3. Confirm the displayed version is 11.7.4.
4. Check browser Console for the first red error.
5. Open Diagnostics for mapping, device, energy-balance, QA, and frontend runtime status.
6. Existing devices and mappings should not be deleted during upgrades.
