# AION EMS Zeus User Guide — v11.7.4

## Install
Replace `custom_components/aion_ems_zeus`, restart Home Assistant, then hard-refresh the browser or reopen the mobile app.

## Main areas
Dashboard shows live operation. Energy shows flow and equipment. Hyper Analytics explains learned patterns. Finance estimates costs and solar savings. Forecast predicts energy conditions. Devices and Configuration manage registry data. Diagnostics validates mappings and platform health.

## Accessibility
Configuration → Appearance and display → Animation mode offers Auto, Full, Reduced, and Static. Keyboard users can use the Skip to main content link and visible focus indicators.

## Safety
Zeus is recommendation-only and does not autonomously control devices.

## Welcome & Smart Setup Wizard (v11.8.0)

The setup wizard opens automatically on a browser that has not completed onboarding. It can also be opened from Configuration → Setup wizard.

The wizard guides users through:
1. Welcome
2. Installed energy systems
3. Read-only smart discovery
4. Device confirmation
5. Home profile
6. Energy goals
7. Intelligence options
8. Dashboard style
9. System readiness
10. Learning journey and completion

The wizard stores presentation preferences in the browser. It does not overwrite entity mappings or import devices without explicit confirmation through the existing Registry and Integration Hub workflows.
